## Run Task 1

Install Python, Jupyter, pandas and numpy. Download the original `Dataset.csv` from the internship's shared dataset folder and place it beside the notebook. Open `Task1_Data_Cleaning/Task1_Data_Cleaning.ipynb` in Jupyter and run all cells from that folder. The notebook writes `netflix_clean.csv` there.

Original dataset and task guidelines: https://drive.google.com/drive/folders/138FPxRQ_heq3HPYOpLuvpnStAPwMMt8W

The supplied clean output has 8,787 rows and 20 columns. It is uploaded at the repository root as `netflix_clean.csv`. The original notebook is preserved without code changes.
