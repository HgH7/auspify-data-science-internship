# Task 1: Data Cleaning and Preprocessing

Cleaned the raw Netflix titles dataset (`Dataset.csv`, 8,790 rows) with Pandas: removed duplicates, handled missing values and placeholder values, fixed formatting, and transformed date, duration, genre and rating columns.

- `Task1_Data_Cleaning.ipynb` - the cleaning notebook
- `netflix_clean.csv` - the clean dataset (8,787 rows, 20 columns)
