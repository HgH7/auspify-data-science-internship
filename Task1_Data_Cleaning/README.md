# Task 1: Data Cleaning and Preprocessing

The original cleaning notebook is included as `Task1_Data_Cleaning.ipynb`, with saved outputs intact.

It removes three duplicate records, handles placeholder missing values, strips whitespace and transforms date, duration, genre and rating columns.

## Input and output

Download `Dataset.csv` from the internship source folder and place it beside the notebook before running:
https://drive.google.com/drive/folders/138FPxRQ_heq3HPYOpLuvpnStAPwMMt8W

Run all cells in Jupyter with pandas and numpy installed. The notebook writes `netflix_clean.csv`, with 8,787 rows and 20 columns. The supplied clean CSV has not yet been uploaded to this repository. Screenshots for submission will be added later.
