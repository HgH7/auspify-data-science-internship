# Part 1: Data Cleaning and Preprocessing

Notebook: `01_Data_Cleaning.ipynb`, with saved outputs.

It removes three duplicate records, handles placeholder missing values, strips whitespace and transforms the date, duration, genre and rating columns.

## Input and output

Get the Netflix titles CSV from Kaggle (https://www.kaggle.com/datasets/shivamb/netflix-shows), save it as `Dataset.csv` beside the notebook, and run all cells in Jupyter with pandas and numpy installed. The copy used here has 8,790 rows. The notebook writes `netflix_clean.csv` (8,787 rows, 20 columns), which is also saved at the repo root.
